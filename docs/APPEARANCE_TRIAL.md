# Desktop appearance trial — 26 October 2026

This first pass changes appearance only: calmer purple branding, clearer type and numbers, consistent spacing and controls, lighter panel boundaries, table headings and light/dark themes. Existing menus and workflows are retained.

## Review on your laptop
1. Update the existing test branch in the same Codespace and refresh the app. A new visual-refresh.css?v=appearance1 stylesheet identifies this trial.
2. Open the offline sales demo for a safe fictional workspace. Review Dashboard, Inventory, an item record, Processing, Sales and Reports.
3. Open Acquire / Value. Check labels, condition choices, costs, save/cancel actions and scrolling. Live provider tests belong in the normal workspace, not the offline demo.
4. Switch between Light mode and Dark mode. Check muted text, selected controls, notices, table rows and keyboard focus.
5. Compare readability at normal laptop zoom. Report the screen, theme and any text or action that is difficult to read.

Review the aesthetic pass before the next usability batch. New navigation, stock preview, faster buying, shared storage and real-phone acceptance are not delivered by this stylesheet.
