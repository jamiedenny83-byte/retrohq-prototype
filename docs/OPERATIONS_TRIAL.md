# Operations trial

Use existing branch retrohq-test-8.3 and private Codespace port8006. Export a backup first.

- Acquire / Value: identify, enter purchase price, optionally set location/trip, then Save item or Save & next on the same screen. Decline closes without adding stock. Quick entry is inside acquisition.
- Confirmed identity plus one exact CeX title/platform match loads its benchmark automatically. Different editions remain explicit. View price evidence retains provider details and Change CeX match.
- Inventory: Organise selected stock edits trip/lot, date and location together. Each physical unit retains its own purchase cost. Missing historic dates stay unknown.
- Processing and Reports: ageing, tied-up purchase cost and listing priorities. Suggestions never change marketplace listings. Update local listing price after you actually change it externally; old prices remain in history.
- Reports: lot investment, confirmed net receipts, remaining investment to recover, realised profit and remaining stock estimate. Net receipts are not profit. Unknown costs and return histories are excluded, not guessed.
- Sales: pick/pack queue and actual cost confirmation, including additional promotion not already included in fees. In-store checkout uses explicit no-postage defaults; online costs need confirmation.
- Automatic Sandbox sync is optional, five-minute polling while the tab is visible. Exact SKU/listing matches can import, conflicts/refunds stay under review; physical returns are never assumed. Session ends on error/tab close. It is not unattended server synchronisation and has not passed live paid-order acceptance.

Open work: production listing/order setup, real order acceptance, full financial/return reconciliation, cross-device shared storage, marketplace listing/relisting/promotions. No UK tax/VAT accounting claims.
